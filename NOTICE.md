# Notice

This repository documents a personal working method.

It contains no employer data. No client names, no colleague names, no internal metrics,
no queries, no system schemas, no commercial figures. The method text was written
separately from the archive it describes, so that it never had to be cleaned: it is
free of that information by construction, not by removal. The skills in `skills/` are the
exception: they were adapted from working versions, with the references to the archive and
its context taken out.

Every example in `examples/` is invented. The companies, people, and numbers there do
not correspond to any real organization, and are not anonymized versions of real ones.
Anonymizing a real case preserves the structure of the relationship, which stays
recognizable to anyone who knows the parties. So the examples were written from
scratch, about a different kind of business.
